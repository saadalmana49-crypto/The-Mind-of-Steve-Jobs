Insanely Great is an Agent Skill that gives AI coding agents product judgment inspired by Steve Jobs' philosophy of simplicity, product excellence, and thoughtful design. Its rule is **remove complexity, keep capability**: make the surface of a product simpler by making its depth smarter, never by deleting what people rely on.

## In this release

- **The skill,** in the open Agent Skills format:
  - seven principles,
  - the placement ladder,
  - six modes (Create, Simplify, Review, Engineer, Decide, Tell),
  - guardrails,
  - output formats,
  - twelve reference files that load on demand.
- **A graded evidence base:**
  - 23 verified Jobs quotes with citations,
  - a list of common misattributions,
  - the documented failures of the approach.
- **Installation** through the skills CLI, as a Claude Code plugin, with the Gemini CLI installer, with the Codex skill installer, or by hand.
- **An eval harness** with 14 scenarios, blind grading, and published transcripts.

## Measured results

In 84 blind-graded Claude Code runs across 14 scenarios:
- Answers with the skill passed **189 of 192** checks, against 146 without it.
- They were preferred in **34 of 42** head-to-head comparisons.
- The skill activated on its own every time.

The losses and limitations are documented in [evals/results.md](https://github.com/saadalmana49-crypto/insanely-great/blob/main/evals/results.md).

## Install

```bash
npx skills add saadalmana49-crypto/insanely-great
```

Other methods are in the [README](https://github.com/saadalmana49-crypto/insanely-great#install). `insanely-great-1.0.0.zip` contains just the skill folder, for tools that accept a zipped skill upload.
