Insanely Great is an Agent Skill that gives AI coding agents product judgment inspired by Steve Jobs' philosophy of simplicity, product excellence, and thoughtful design. Its rule is **remove complexity, keep capability**: make the surface of a product simpler by making its depth smarter, never by deleting what people rely on.

## In this release

- **A shorter, sharper skill.** `SKILL.md` loads at about 3k tokens, down from about 4.4k, with the same principles, modes, and guardrails.
- **Honest simplification:**
  - A simplified checkout keeps the itemized cost and the terms people are entitled to.
  - The skill won't build a version that is deceptive, unsafe, or non-compliant. It delivers the closest compliant design instead and says why.
  - A capability ledger has to name what each removed item served.
- **More concrete answers:** exact error text, the arithmetic behind estimates, overlapping concepts merged, and a check for existing tools before building anything.
- **Broader coverage:** pricing, data pipelines, permissions, notifications, and removing features cleanly.
- **Ten new eval scenarios,** and a harness that compares skill versions head to head.

## Measured results

In blind-graded Claude Code runs across 24 scenarios, 3 runs each:
- Version 1.1.0 passed **320 of 324** checks, against 307 for version 1.0.0 and 259 with no skill.
- The judge preferred it over no skill in **64 of 72** head-to-head comparisons, and over 1.0.0 in **51 of 72**.
- On the new scenarios, a run cost $0.050 on average, against $0.056 for 1.0.0 and $0.031 with no skill.

Answers got about 10% longer than 1.0.0's. The ten new scenarios were also used to revise this version, so its gains there are partly tuning. The losses and limitations are documented in [evals/results.md](https://github.com/saadalmana49-crypto/The-Mind-of-Steve-Jobs/blob/main/evals/results.md).

